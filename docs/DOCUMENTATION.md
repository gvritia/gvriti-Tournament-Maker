# Сопроводительная документация

Сопроводительная документация Tournament Maker хранится в репозитории вместе с исходным кодом. Она нужна для установки, запуска, тестирования, описания архитектуры и дальнейшего сопровождения проекта.

## Основные документы

- `README.md` в корне репозитория - общее описание проекта, быстрый запуск и структура.
- `backend/README.md` - подробная инструкция по backend.
- `frontend/README.md` - запуск и назначение клиентской части.
- `docs/README.md` - навигация по документации.
- `docs/PROJECT_CONTEXT.md` - предметная область и бизнес-правила.
- `docs/ARCHITECTURE.md` - архитектура приложения.
- `docs/ACCEPTANCE_CASES.md` - приемочные сценарии.
- `docs/INSTALLATION.md` - установка и настройка.
- `docs/TESTING.md` - тестирование.
- `docs/DEPLOYMENT.md` - ввод в эксплуатацию.

## Автоматическая API-документация

FastAPI формирует OpenAPI-документацию автоматически на основе маршрутов и Pydantic-схем.

После запуска backend доступны:

- Swagger UI: `http://127.0.0.1:8000/docs`;
- ReDoc: `http://127.0.0.1:8000/redoc`;
- OpenAPI JSON: `http://127.0.0.1:8000/openapi.json`.

## Назначение документации

Документация позволяет:

- повторить установку проекта на новой машине;
- понять структуру backend и frontend;
- проверить основные пользовательские сценарии;
- выполнить автоматические тесты;
- подготовить проект к демонстрации;
- сопровождать проект после изменения бизнес-логики.
