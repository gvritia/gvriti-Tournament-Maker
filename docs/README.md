# Документация Tournament Maker

Папка `docs` содержит проектную и эксплуатационную документацию для учебной системы Tournament Maker. Эти материалы используются для описания архитектуры, установки, тестирования, ввода в эксплуатацию и сопровождения проекта.

## Основные документы

- `PROJECT_CONTEXT.md` - описание предметной области, сущностей, бизнес-правил и текущего состояния проекта.
- `ARCHITECTURE.md` - архитектура backend-приложения, разделение на слои и ключевые технические решения.
- `ACCEPTANCE_CASES.md` - приемочные сценарии для проверки основных возможностей системы.
- `INSTALLATION.md` - установка и настройка проекта.
- `TESTING.md` - автоматическое и ручное тестирование.
- `DEPLOYMENT.md` - локальный и демонстрационный ввод в эксплуатацию.
- `DOCUMENTATION.md` - описание сопроводительной документации проекта.
- `DEVELOPMENT_LOG.md` - журнал разработки.
- `BACKEND_REVIEW_LOG.md` - журнал проверки backend-части.

## Связанные README

- `../README.md` - общее описание проекта и быстрый запуск.
- `../backend/README.md` - подробная инструкция по backend.
- `../frontend/README.md` - инструкция по frontend-приложению.
